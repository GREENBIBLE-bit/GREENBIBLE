# GREENBIBLE

## Voice Scripture & Church Presentation Software for Windows

**The Pastor Speaks. GREENBIBLE Displays the Scripture.**

GREENBIBLE is a Windows church presentation application designed to help churches display Bible Scriptures, worship song lyrics, announcements, and live presentation content from one computer.

It combines Bible presentation, voice Scripture recognition, worship lyrics, announcements, and NDI output for professional church production workflows.

---

## ✨ Main Features

### 📖 Voice Scripture Recognition

GREENBIBLE is designed to listen for spoken Scripture references and help identify the Bible passage being spoken.

The operator can also use manual Bible search and selection when required.

### 📺 Live Bible Presentation

Display Scripture clearly on the church presentation screen with a dedicated live presentation interface.

GREENBIBLE includes support for the King James Version (KJV) Bible database.

### 🎤 Worship Songs

Manage and present complete worship song lyrics.

GREENBIBLE does **not** use a slide system for songs.

The song remains a complete lyric document, while the live display can show:

- 1 line
- 2 lines
- 3 lines

The NEXT control moves through the lyrics.

### 📢 Church Announcements

Create and manage church announcements for display during services and church programs.

### 🎥 NDI Output

GREENBIBLE includes NDI presentation support for professional video production workflows.

This allows the GREENBIBLE presentation output to be used with compatible NDI production systems such as vMix.

### 🎨 Presentation & Themes

GREENBIBLE provides presentation controls and visual settings for church environments.

### 🔐 License & Activation

GREENBIBLE includes a license and activation system for managing application access.

---

# 🖥️ Windows Requirements

GREENBIBLE is designed for Windows computers used for church presentation and media production.

Recommended setup:

- Windows 10 or Windows 11
- USB or built-in microphone for voice recognition
- Stable computer suitable for live presentation
- NDI-compatible network when using NDI output
- vMix or another compatible NDI production system when required

Actual performance may vary depending on computer hardware, microphone quality, network configuration, and the selected production workflow.

# 📦 Installation

1. Download `GREENBIBLE_Setup.exe` from the latest GitHub Release.
2. Run the installer.
3. Follow the Windows installation instructions.
4. Launch GREENBIBLE.
5. Configure your microphone and presentation settings.
6. Test the Bible presentation before using GREENBIBLE in a live church service.

For NDI production, configure the NDI output and connect GREENBIBLE to your compatible production environment.

---

# 🎙️ Voice Workflow

A typical church workflow can be:

1. Pastor begins speaking a Bible reference.
2. GREENBIBLE listens through the configured microphone.
3. The application processes the spoken Scripture reference.
4. The matching Scripture can be identified.
5. The operator can present the Scripture live.
6. GREENBIBLE can provide the presentation output through the configured display or NDI workflow.

Manual Bible search remains available when voice recognition does not identify the desired passage.
